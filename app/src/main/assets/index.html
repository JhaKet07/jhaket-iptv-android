JhaKet IPTV · Configuración

Reproducción en vivo

En un canal en vivo solo existe lo que ya se emitió, así que el único colchón contra los cortes es reproducir más atrás del directo: el búfer es el retraso. Elegí qué preferís cuando la conexión viene lenta.

Guía de programación (EPG)

Importá XMLTV en formato .xml o .xml.gz. La guía se guarda en este dispositivo, se asocia por nombre o ID del canal y se actualiza sola cada 12 horas.

Sin guía importada.

Usuarios y accesos

Creá cuentas para compartir el reproductor. Solo vos, como administrador, ves esta sección y las opciones para agregar o quitar listas M3U.

Dispositivos

Cada vez que alguien entra, su dispositivo queda registrado acá. Aprobalo indicando por cuánto tiempo puede ver el contenido, o rechazalo.

Sinopsis y pósters automáticos

Completa la sinopsis, el año y el póster de películas y series consultando TMDB, una base de datos de cine con datos reales (no inventados). Necesitás una clave gratuita: creás una cuenta en themoviedb.org y la copiás desde Configuración → API. La clave queda guardada solo en este dispositivo, así que no viaja si compartís el archivo.

Sin configurar.

Categorías personalizadas

Renombrá una categoría existente. Escribí el nombre original y el nuevo nombre.

Control parental

Protege el acceso a películas y series con un PIN local de 4 a 8 dígitos. El PIN no se envía a Supabase.

Supabase · Sincronización

Configuración del proyecto. Para sincronización segura por dispositivo, JhaKet utiliza una Edge Function protegida; nunca pegues aquí la clave service_role.
